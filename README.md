# 数字神探 Digital Detective

面向中文刑事案件研究的**本地离线 AI 工作台**。输入或上传文字材料，即可完成证据提取、线索核查、矛盾分析和多轮追问，查看带原文引用的分析结论与证据关系图。

**本机推理 · 无需模型 API Key · 原文引用可追溯 · 支持持续补充线索**

## 应用与功能

适用于案件材料整理、证据关系研究、线索补全和分析过程复核。

| 功能 | 使用方式与输出 |
| --- | --- |
| 材料导入 | 直接粘贴文字，或上传 TXT、Markdown、DOCX、有文字层的 PDF |
| 证据提取 | 从材料中提取线索，保留连续原文引句与字符位置，支持点击引用回看依据 |
| 案件分析 | 核查证据、梳理人物与关键经过，呈现矛盾、竞争解释和待补线索 |
| 多轮追问 | 证据不足时提出问题；补充材料后继续分析，并保留各轮记录 |
| 第二轮复核 | 对分析结果再次检查，帮助发现遗漏及不一致 |
| 证据图谱 | 通过可点击节点查看证据及其关联 |
| 案件管理 | 本机账户与案件隔离，支持持续对话、JSON记录导出和删除 |
| 版本追溯 | 页面显示模型状态，导出记录包含所用模型版本；激活权重与配置按哈希校验 |

分析以提供的文字证据为依据；材料不足时可以返回“证据不足”，并列出需要补充的信息。

## 快速开始

### 环境要求

- **Apple Silicon Mac**，按24GB统一内存设计；当前不支持Windows本地推理。
- 首次准备需联网安装依赖、下载基座模型；准备完成后可离线启动。
- 在普通Mac终端运行，以便MLX访问Metal GPU。

### 已准备好的本机

在项目目录运行：

```bash
sh run_offline.sh
```

浏览器打开 **<http://127.0.0.1:8765>**，注册本机账户或登录即可使用。

### 新机器首次安装

```bash
git clone https://github.com/Momingzzhh/digital-detective.git
cd digital-detective
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-mac.lock
cp .env.example .env
chmod 600 .env
.venv/bin/python scripts/download_local_model.py
.venv/bin/python scripts/check_local_setup.py --verify
sh run_offline.sh
```

**新机器默认使用基座模型。** GitHub提供代码、配置和汇总报告，私有训练材料及微调权重不随仓库分发。已有合法持有的本地适配器时，按[模型核验与启用说明](docs/local_delivery.md#后续扩充和替换模型)操作；页面会显示实际使用的模型状态。

运行时无需模型API Key。离线启动不会自动安装依赖或下载模型，也不会回退到云端推理。

## 使用流程

1. **导入材料**：点击“填入合成示例”体验，或输入／上传自己的文字材料。
2. **创建案件**：点击“开始分析现有材料”，等待证据提取、工具核查、分析和复核完成。
3. **查看依据**：在“分析结论”中点击引用定位原文，在“证据图谱”中点击节点查看关联。
4. **补充线索**：在右侧填写新信息并发送，系统自动开始下一轮分析。
5. **保存结果**：点击“导出记录”保存完整JSON，便于后续复核。

长材料处理时间会更久。超出上下文容量时，系统会明确提示，不会静默删减证据；扫描PDF需先转成文字。

在终端按 `Ctrl+C` 停止网页服务，之后运行同一启动命令即可恢复使用。账户和案件保存在 `runtime/detective.sqlite`，重启服务无需删除数据库。

## 本地模型与研究能力

Agent基座采用 **Qwen3 4B Instruct 2507的MLX四位模型**，模型文件逐一校验，见[本地模型清单](data/local_model_manifest.json)。本机微调使用QLoRA适配器，训练输入、配置和权重均有版本记录。

项目提供五维案件标注与研究复核能力，涵盖**证据层级、逻辑链、矛盾点、推理深度和对话轮次**。训练、验证和测试材料分开管理，原文引用与来源绑定可检查。当前七案均保持实际两层推理，其中5案仍待人工复核；600案复杂基准及完整人工验收仍是后续研究目标。

需要复核材料时，在 `.env` 设置 `RESEARCH_REVIEW_ENABLED=true`，重启服务并登录后访问 <http://127.0.0.1:8765/research>。该页面供研究人员核对原文、答案依据和标注，普通案件分析不需要开启。

训练与复核的完整操作请参阅[训练及验收规程](docs/local_training_protocol.md)，README仅展示当前成果和使用入口。

## 验证与使用边界

在已安装依赖的项目目录执行：

```bash
# 软件测试
.venv/bin/python -m pytest -q

# 本地模型与文件检查
.venv/bin/python scripts/check_local_setup.py --verify

# 离线推理检查
.venv/bin/python scripts/smoke_offline.py
```

- 系统处理文字证据，不鉴定原始指纹、DNA或视频，不连接警务数据库。
- 模型分析及第二轮复核仍可能出现语义错误；引用有效不等于推断正确，结论需由研究人员复核。
- 软件测试和训练来源上的边界检查不等于新案件准确率，评测汇总也不是对任意案件的效果保证。
- 当前提供本地应用与GitHub源码，未提供公网托管服务。
