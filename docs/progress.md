该批汇总见[选案反馈处理统计](../data/returned_selection_report.json)。它与既有[已确认校准反馈统计](../data/calibration_feedback_report.json)属于不同阶段，不能直接相加当作正式通过数量。具体Word、核对身份、原文、逐案意见与工作副本均留在本机。

## 11月8日拟定的后续研究路线

1. **先核对局部证据行为，再扩充训练来源。** 优先真实三层，不足时可接受实际两层；来源不充分、答案无支持、伪矛盾和非必要依赖仍拒绝。待测Agent成绩、验证案和测试案语义不用于训练选案。
2. **冻结新的小批量版本并训练。** 自动审核通过的新训练案允许待人工复核；从政策、原始来源、引用和质检重新派生，完整检查长度后实际更新权重，再检查新权重的离线行为。保留每批材料、代码、配置及适配器哈希，避免反复训练相同两案代替扩充数据。
3. **继续积累完整基准。** 长期组建600个不同案件组，保持420 / 90 / 90，三层基准独立记录。至少90个验证案和90个测试案仍须由真人逐案核验来源、答案及标注，不由提前训练自动批准。
4. **准备完整真人验收。** 数据、模型和全部留出材料审核准备好后才进入下一阶段；小批量训练完成不等于项目完整验收完成。
5. **完成人工交互验证，再开启独立测试。** 真人完成全部90个验证案，整案准确率达到70%后冻结模型和数据，再完成90个测试案；失败、拒答、超时和未完成均保留在分母。

目前没有新的准确率或正式验收完成结论。具体复现命令、隔离规则与验收条件见[本地训练规程](local_training_protocol.md)。
