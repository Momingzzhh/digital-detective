## 可操作的 v3 门槛

1. **原文区段分类先于切片。** 标记公诉指控、法院查明、理由、判决、原始证据条目。仅允许从有明确证言、供述、鉴定、勘验等来源标题的证据条目内部选片段；不得通过从段中间开始来逃避前文司法认定标签。证据来源标题缺失时拒绝或补选包含真实标题的连续范围，不能生成标题冒充原文。
2. **罪名检测覆盖标题变体。** 对gold罪名移除“罪”后检查标题和司法分类段，配合语境审查。普通证人的自然行为描述不等同裁判罪名，不应仅机械删词。法院认定和定罪量刑字段始终不得发布。
3. **明确范围且不偷换任务。** 判决当事人列表只证明“本份裁判对象”，不能证明“全部作案者”。出现已判、另案、在逃或证据明确共同实施而gold未覆盖的参与者时，案例不得进入完整作案者识别基准。不能通过把任务默默改为预测本案被告人来刷指标。
4. **每个事实案件group最多一条。** 应查明撤销、重审、改判及终审的有效结果，选择适当有效裁判。无法确定顺序和效力时暂不入基准，不得随机选一篇。本文第1/6条说明同组罪名可能改变。
5. **经过按原子断言检查。** 每个时间、地点、人物、金额和行为分别映射到发布的 evidence_id；不能只证明它在隐藏全文中出现。摘要不得扩大数量或鉴定结论。受害人匿名映射不可见时，gold应使用可见匿名实体，不考恢复隐藏实名。
6. **独立记录缺口。** 保存逐条source/checkpoint和付费审核记录；修改抽取或gold需新版本，不覆盖v2。展示机器审查、agent审计、人工专家复核三个不同数量；此次人工专家复核仍为0。

上述审计没有运行待测agent，完全不按答题结果筛选。下一步可对两个“可修复候选”做明确版本化修正，再经独立阅读审查，得到少量可信示范；1000+目标在完成实际质量工作前保持未达成。
