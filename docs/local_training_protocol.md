# Mac离线训练与五维评测规程

2026年10月21日起，本轮要求替代旧版1000案及90%目标：准备500+复杂刑案，实际微调本地模型权重，先实现24GB统一内存Mac。第一轮整案准确率门槛为70%。Win11离线兼容留待后续阶段，当前MLX运行与训练不声称支持Windows。

## 数据定义

目标冻结600个不同案件组，训练420、验证90、测试90，严格70/15/15。沿用既有同案分组和集合身份，只在各集合中选择相应配额，不把旧训练案改派到测试集。候选池内按分组哈希固定顺序；标注时优先处理原始裁判记录有多个行为人的组，导出仍按固定哈希取各集合配额。这个来源元数据优先级可能使首批偏向共同犯罪，不能将首批分布代表全部刑案；不使用Agent答题成绩选案。

每案至少6条有效线索，覆盖3类证据，存在原文支持的真实矛盾或多个待排查对象，并需要至少3层证据关联。结构筛选仅检验数量与来源，不自动认定“有效”“矛盾真实”或“推理必要”。单一被告有罪的历史补充分组不并入本轮现代案件基准。

五维标注依次为：

1. 证据层级：直接观察或原始记录、间接印证、转述或背景，逐条绑定证据ID。这是证据作用的初步分类，不是司法证据效力排序或绝对真实性评级。
2. 逻辑链：可核验的简短主张、支持证据和先前步骤依赖，构成有向无环图。不输出或收集模型私密思维链。
3. 矛盾点：两个相互冲突陈述的连续原文引句、冲突事项、处理状态及解决依据；可位于不同证据，或同一材料中两个不重叠的原文片段。没有真实矛盾时留空，只有多个真实待排查对象满足另一条件时才可入选。
4. 推理深度：标注依赖图最长路径。程序可核查图，是否必要且没有同义重复凑深度由人工复核。
5. 对话轮次：训练案例记录来源约束的模拟轮次；验证、测试和新案记录真实研究人员完成的分析轮次。尚未发生真人交互时为null，不能填0冒充已测试。一次初始分析也算一轮，失败尝试另计。

完整标注、原始文书和隐藏答案保存在本机私有目录。可见材料只包含案号内部ID、分组、集合及原始证据。逻辑链、真实结局和审核意见不进入 acting agent 上下文。模型初标和机械校验均标记为未人工核验，至少验证与测试全部需要研究人员复核。

## 本地模型与标注

基座使用Apache-2.0许可的[Qwen3 4B Instruct 2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507)，采用[MLX社区4位转换](https://huggingface.co/mlx-community/Qwen3-4B-Instruct-2507-4bit)，固定修订50d427756c6b1b2fe0c0a10f67fbda1fc8e82c1b。镜像仅供文件下载，Git blob及LFS哈希逐文件核对，下载清单见data/local_model_manifest.json。

联网准备仅用于安装依赖和下载文件。标注、训练及推理采用本地文件，开启HF_HUB_OFFLINE与TRANSFORMERS_OFFLINE；没有云端模型回退，不读取阿里云密钥，不新增云端费用预占。旧账本仍保留待对账。

本地[Outlines约束生成](https://github.com/dottxt-ai/outlines/blob/main/docs/features/models/mlxlm.md)限制JSON格式及允许的编号；它不能保证事实正确。紧凑标注通过已知句子ID还原原始引句，不使用模型改写的句子冒充原文。未知引用、虚构引句、缺失层级、循环或不足三层的推理链仍被拒绝。只允许已知句子ID还原到所属证据ID、完全相同姓名去重，记录修复前后值；不合并别名、不补造人物或语义。修订标注协议后可重试旧协议失败记录，原始输出保留归档，不修改分组和复杂度门槛。

## 实际权重训练

使用[MLX官方QLoRA流程](https://github.com/ml-explore/mlx-lm/blob/main/mlx_lm/LORA.md)，在4位基座上更新LoRA适配器。训练脚本记录数据哈希、训练组、参数、排除的超长示例及权重哈希；学习后的LoRA B矩阵必须出现非零更新，才能标记实际训练发生。修改提示词不计作权重训练。

鲁棒性训练样例只来自训练组：完整证据、顺序扰动、全部证据缺失时的拒绝定论、明确标识的合成提示注入、以及按原始证据逐步释放的模拟对话。合成攻击不计入真实案件或原始证据数量。没有覆盖到的边界不能因这些训练样例而宣称已保证。

所有训练组的完整案件任务必须进入训练。每类边界变体按固定哈希抽取训练组数量的10%，模拟对话的每次回答展开为一个监督前缀，使中间追问也实际参与损失计算。正式训练迭代数必须覆盖全部被接纳样本至少一遍，并对齐4步梯度累积；8个微批次仅有2次优化器更新。训练报告记录实际迭代、非零权重和内存，不用token损失充当整案准确率。

序列长度逐条检查，超长示例记录并排除，不静默截断证据。若某个训练组的完整案件任务无法容纳则阻止训练，不能只保留空证据拒答样本冒充覆盖该案。测试材料不会写入训练目录。验证损失只用于开发，不能代替70%整案准确率。小样本pilot只能验证工程流程，不能开启正式验收。跨进程模型互斥避免标注、训练与网页推理同时抢占GPU。

## 人工复核与真人验收

在.env设置RESEARCH_REVIEW_ENABLED=true后，登录本地网页并访问/research。研究人员逐案核对完整原文、隐藏答案与五维标注，填写核验项和说明。复核记录绑定当前材料及用户身份，不能由脚本批量冒签。

正式模型和完整数据准备好后，启动验证会话。Agent起始只得到两条证据，研究人员根据问题从原文中释放其他证据，不能在验收会话自由补造事实。每案最多12次分析尝试。结束时自动比对罪名与人物集合，研究人员评定经过是否完整且没有无依据事件；失败或拒答不能从分母删除。

完整验证集评分且整案准确率达到70%后，才允许开启测试集。首次测试冻结模型与集合绑定；同一测试案只能启动一个会话、提交一次最终评分，不选取多次运行中的最好结果。打开测试集后，训练脚本禁止继续使用同一测试周期调参。

汇总必须覆盖全部90个验证案及90个测试案，分别报告整案、罪名、人物、经过、失败和轮次，另附Wilson 95%区间。只有真实权重训练、来源人工核验、完整验证集及最终测试集均通过门槛，才标记training_complete=true。70%是本轮验收指标，不是对任意新案件的可靠性保证。公开旧案预训练污染、未发现的关联案件和同模型初标偏差仍须披露。

## 复现顺序

```bash
# 一次联网准备；Mac Apple Silicon与Python 3.12
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-mac.lock
.venv/bin/python scripts/download_local_model.py
# 确认已有data_sources.md所述原始来源和去重审计，再离线处理
.venv/bin/python scripts/prepare_five_dimensions.py
.venv/bin/python scripts/annotate_five_dimensions_batch.py --limit 1980 --batch-size 4 --retry-rejected
.venv/bin/python scripts/assemble_five_dimensions.py
# 必须已导出完整600案；不足会被阻止
.venv/bin/python scripts/train_local.py
# 选择本地已训练适配器：在.env设置LOCAL_ADAPTER_PATH为run.json中的adapter_path
sh run_offline.sh
# 在网页完成人工复核及真人验证集评分后汇总，测试集仍独立保留
.venv/bin/python scripts/summarize_acceptance.py
# 最终完成测试集评分后再次汇总
.venv/bin/python scripts/summarize_acceptance.py
```
