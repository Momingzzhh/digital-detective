## 本地文件

最新目录由本地`data/research_bundle_report.json`的`local_directory`给出，位于`data/processed/research_bundle/<版本哈希>/`。同一版脚本和冻结导出生成相同目录；原版本保留，不覆盖旧材料。

- `visible-only.zip`：两组独立的可见JSONL、404份中文TXT和使用说明。TXT供网页建案、人工查阅使用；没有写入隐藏结局字段或原始全文。内容本身是否存在语义上的结局泄漏仍需复核。
- `review-private.zip`：相应的隐藏结局、原始文书或英文XML、来源、机器整理全记录、审核结果及复核目录索引。仅供隔离复核，不可传给待测agent。
- `visible/`与`review_private/`：上述两包的解压内容，保持现代与历史、train/dev/test分开。
- `manifest.json`：所有交付文件的大小和SHA-256，以及上游冻结导出的7份JSONL哈希。

这些文件被Git忽略，不公开案件正文、答案、账户、密钥或预算账本。GitHub只发布代码、文档及汇总哈希。代码MIT许可不覆盖第三方案件材料；历史来源及中文译文遵循署名非商业的CC-BY-NC-4.0许可，来源与偏差见[数据集卡](dataset_card.md)。

## 整理过程与复现

本机已有完整来源及导出材料时运行：

```bash
.venv/bin/python scripts/package_research_bundle.py
```

脚本无需网络和模型密钥。它先校验现代v3.7和历史v1.5导出清单的文件哈希，检查可见字段白名单、答案对应关系及同组不跨集合，再读取选中案件的本地原始记录。现代材料重新核对事实、全文哈希和引文偏移；历史材料由原始XML重建证言，核对中英句子绑定、翻译及审核结构。来源不匹配则失败，不自行补写线索。导出目录完成后才发布，重复运行检查已有包的文件完整性。

全量案源仍在`data/raw/`及`data/processed/`保存。研究包只复制404案的原始记录，避免重复打包整个大型语料。

## 使用与后续核验

人工演示先用train或dev中的TXT。在本地网页注册或登录后，可上传TXT建立自己的案件；当前模型账户不可用，自动分析要待账户恢复后才能继续，不因整理包生成而恢复。

test用于保留测试划分，不得用于提示词调参或选择通过样本。持有完整复核包的人能看到答案，因此不应作为同一轮盲测的操作者或评分裁判；需冻结核验后的集合、隔离答案访问并记录操作历史，才能作独立测试声明。公开旧案的基础模型预训练污染无法排除。

下一阶段仍需按[独立审核规程](human_review_protocol.md)逐案核对原文、线索充分性、结局、共同作案人、翻译与关联分组。机器通过及小规模抽查均不能代替这一步，也不能据此承诺90%准确率。
