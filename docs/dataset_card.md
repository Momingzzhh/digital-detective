# 数据集卡：案件证据研究材料

本项目整理真实公开记录，供研究人员开发中文案件证据分析系统。数据下载、结构筛查、机器审查、独立阅读及正式验收是不同阶段。最新数量见[状态报告](../data/dataset_report.json)；正式验收未完成前不称为1000案合格基准，也不宣称90%准确率。

## 分组与预期用途

现代中文分组由LeCaRD及衍生全文、MNBVC裁判文书构成。只从明确证言、供述、鉴定、勘验等条目提取连续原文，屏蔽司法查明、指控、理由及判决。历史英国分组来自Old Bailey，独立保存1834—1913年庭审证言及中文翻译，不套用中国现行法律，成绩不得并入现代案件指标。[来源说明](data_sources.md)列出固定版本、许可证、下载清单与复现命令。

可用于证据定位、翻译质量检查、参与者范围核查、交互式证据释放和开发期软件验证。当前不能作为已验证的自动破案能力、客观有罪判断或真实司法决策依据。历史单一被告有罪样本存在明显基线偏差，容易凭中性人物映射猜中当事人；这个基线必须与最终结论指标一起报告。

## 文件与字段

| 本地私有文件 | 内容 |
|---|---|
| `data/raw/` | 固定版本原始文书、Parquet与完整XML；按下载清单校验 |
| `data/processed/*candidates.jsonl` | 来源候选、原始记录、初步分组和划分；不代表已验收 |
| `data/review/v3_*/`、`oldbailey_v1/` | 逐案模型标注、来源审计、翻译、质检及错误检查点；旧尝试归档 |
| `data/processed/review_bundle/*/visible/{train,dev,test}.jsonl` | agent可见证据；禁止夹带隐藏标签、原文指控标题、裁决与审计理由 |
| `data/processed/review_bundle/*/hidden/{train,dev,test}.jsonl` | 真实来源的结局、参考经过、来源、原文偏移和审计；只供隔离的核验与评分 |

可见证据有`id`、`text`、`kind`。历史视图另有`stratum`、`jurisdiction_context`和原始XML人名标签导出的中性`participant_references`。它们只解释称谓，不证明任何人有罪。真实字段及允许列表以导出脚本为准，不能直接把机器检查点交给agent。

历史导出还生成按内容哈希命名的`visible_text/<导出版本>/<划分>/*.txt`，可以直接在网页上传。TXT仅包含法域日期、中性称谓对应和中文材料，不含隐藏裁决或类别；原始英文和完整来源另存于私有核验包。旧TXT导出保留，最新版本见历史导出报告。

历史隐藏类别使用原始`category/subcategory`代码。英文证言保留XML段及哈希，中文按句子ID逐项对应；参考经过绑定英文原句及中文字符偏移。来源、分句或流程版本变化会使旧绑定失效。导出重新读取固定Parquet并复核XML段、标签连接、双语句子、人物集合和审计完整性。现代与历史分别导出，不生成一个混合准确率。现有现代评测脚本拒绝历史数据，历史类别评测尚待实现与验收。

## 选择与划分

来源候选按预先固定的哈希排序，不使用待测agent的答题结果选案。历史`admission-priority`仅优先处理原文出现承认行为措辞的候选，再按固定哈希排序；正则可能误中证人的普通“I took”等表述，绝不将其当作有效供述或通过依据。这种选择偏向容易还原、含承认表述的案件，不能推断总体案件表现。

现代跨来源关联结合来源组、全文及事实哈希、法院范围内案号；已知跨集合冲突隔离。历史按规范化当事人姓名分组，最多一例，不同案件同名可能被过度合并，别名或不同参与者的关联案可能漏识别。原划分冻结，不为凑数量重新分配。用于调试的历史案件组登记为开发材料，其test记录在导出时排除。当前没有训练或微调产物；文件名train只是预留用途。

## 审核、费用和已知限制

机器审核使用Qwen3.8系列；历史v1.5用Max执行来源审查、证言翻译及双语质检，Flash选择来源句子与参与者。译者不接收隐藏罪名或裁决。相同系列模型仍可能共享错误。独立agent阅读发现的错配、未列共同实施者及翻译错误单独记录并隔离，不冒充人工专家审核。[质量审计](quality_audit.md)记录失败及修复，而不只报告通过项。

所有付费调用由同一SQLite账本预占和结算，硬上限500元。超时保留不确定预占，不能删除账本换取更多额度。数据构建另设较低软上限，未完成任务保存为待续。格式错误重试保留旧值且有次数上限，不按agent答题成绩重试选案。

公开旧案可能被基础模型预训练收录；下游隐藏答案和未训练并不排除记忆。公开记录中的裁决是历史或司法来源标签，并非客观有罪事实的保证。现代MNBVC来源有作者披露的乱码清洗还原问题，SHA校验仅证明与指定发布文件一致。缺失指纹、DNA或其他材料必须保留为未知，不允许补造。

正式冻结按[审核规程](human_review_protocol.md)逐案核验。人工审核仍为0。只有独立分组、线索充分、全部参与者与有效结局均经过实际核验，且完整隐藏测试达到门槛，才能声明达标。

代码采用MIT。Old Bailey原始记录及衍生译文按CC-BY-NC-4.0署名、非商业使用，其他来源遵循各自条款。公开GitHub仅发布代码、来源清单、统计及哈希，不发布原始案件、证言译文、隐藏答案、密钥或审核者身份。本机研究包不因生成而获得新的再分发许可。
