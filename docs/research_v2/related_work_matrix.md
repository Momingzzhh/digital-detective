## 现稿引用审计

`paper/main.tex` 的11篇外部文献均已找到匹配题名和原文入口；另一个 repository 条目指向本项目，是代码入口而非学术比较证据。保留的作者缩写与对应页面作者顺序相符。没有把搜索摘要或未访问链接当已读论文。后续写作引用新增文献仍须同样核对。

现稿可支持“法律任务适配、工具循环、局部运行、证据引用与逐主张评测已经有人研究”。它不支持“本方法优于既有方法”“首次调查Agent”“只靠本地4B即可可靠定罪”。未来法律标签按来源一致性/争议分别报告；非专家复核不能宣称法律专家认证。

## 当前贡献定位及可证伪条件

当前按**数据/评测设计和受控实证研究**定位；尚无足够证据主张新算法。候选贡献是现代中文案件的来源绑定、动作条件释放、真实未命中/永久缺失/用户可补充的分层评测，以及低资源本地模型的成本—支持性权衡。H1—H4见协议。

只有同来源、同初始观察、同预算对照支持后才能宣称有效。若M1不优于B3，保留负结果，转为可复现环境/错误分析贡献；若新环境与既有任务实质重叠，不用换名称包装新颖性。专家法律标注、数据许可、独立测试规模和完整related-work覆盖仍是论文投稿前的门槛。
