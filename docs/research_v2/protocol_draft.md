# 开发协议 v1（2026-11-12，T05）

本版本冻结开发研究问题和默认控制条件，配套 `configs/research_v2/development.json`。这是开发协议，不是最终测试注册、实验结果或执行授权。当前只执行T01—T05；正式样本量、法律标签、dev选型和test封存分别在后续任务完成。修改本协议需新版本和原因，禁止看test后改指标。

## 研究问题与范围

在相同初始观察、模型和调查预算下，显式记录证据缺口、竞争解释及可获取性，能否改善源文书支持的案件判断，并在无法取得材料时提出有针对性的求助？只研究现代中国大陆中文刑事文字材料。来源裁判标签、已观察证据可支持结论和未知事项分别保存。Old Bailey单列。输出是研究判断，不是司法裁决。

所有模型计算在Apple M4/24 GB完成，不调用外部模型API、不租GPU。既有4B四位MLX基座是默认对照起点，14B仅作为后续本地标注/审核候选；不同时加载。更大模型比较属于T16，当前不执行。

历史74.7%汇总无效于新实验；五案已激活、七案未激活。所有历史训练组及其变体保持训练身份，训练重放不称独立dev。1,999结构候选不称合格数据。新增标签及训练不属于本轮。

## 观察、动作和预算

环境保管完整允许证据，Agent仅接收当前已释放观察；隐藏裁判、未释放ID、证据目录和gold不得进入提示。源文书中的法院归纳和裁判结论不作为可见调查证据。没有请求相应材料就不得提前释放。

开发默认：最多8次环境调用、最多2次用户求助；无效、重复、未命中都计入调用预算，所有条件使用同一计数器；finish不计调查调用。统一每次生成上限2048输出tokens、12288输入上下文起点，temperature=0。所有模型调用（含内部规划/复核）计入总tokens、耗时和调用数，不以动作数隐藏计算差异。T15实测后允许以新开发版本调整长度/成本上限，正式测试前T42冻结总生成预算。

环境状态区分found/no_match/not_available/precondition_not_met。合法检索失败不等于证据不存在。求助应引用已观察缺口及失败动作；源约束模拟用户只有在问题匹配可补充材料时提供内容，否则明确无法补充。用户材料不因到达即自动真实。无新信息、预算耗尽或支持充分时终止，记录原因。

## 比较条件与信息公平

| ID | 条件 | 用途 |
|---|---|---|
| B0 | 基座只回答初始观察 | 诊断下界，不与更多信息直接作方法因果比较 |
| B1 | 固定释放顺序，预算匹配 | 区分策略选择与材料增加 |
| B2 | 合法动作随机选择，固定种子 | 随机调查对照 |
| B3 | 普通工具Agent，无显式缺口状态 | 主要研究对照 |
| M0 | 缺口策略，无动作SFT | 分离策略工程效果 |
| M1 | 缺口策略+动作SFT | 候选方法 |
| D0 | 相同来源与训练计算预算，固定释放对话SFT | 监督形式对照 |
| O0 | 所有允许证据一次给出 | 更多信息诊断参考，不称数学上界 |

B1/B2/B3/M0/M1/D0共享案件组、初始观察、环境、用户通道、动作及输出预算；记录实际读取材料量。M1和D0使用相同基座、来源案件、有效监督token预算，并报告优化器步数和真实资源成本。不可用明显较差提示或减少基线信息制造优势。

## 主指标及分母

案件组是独立单位。每组多个episode/种子先在组内平均，再跨组比较，不增加独立样本数。默认同时报告可解与未决分层；总体为两层各0.5权重的宏平均，任一层缺失则总体记NA，不偷偷重新归一化。最终测试分层和权重在T42冻结。

可解成功：关键事件、全部有证据支持的行为参与人及角色正确，法律标签按已核验标准一致，并且每项关键结论由已观察材料支持。未决成功：不作无依据确定指控，保留与已观察材料相容的解释，明确关键缺口。可解案永远拒答视为未完成；未决案合理拒答可成功。超时、错误、无结果计失败并保留在分母。

法律标签有争议时不让非专家凭印象判唯一罪名；独立报告来源一致性与争议。是否进入带法律标签的确认性主指标，需后续完成可信标签审核并在测试前冻结。未满足时只报告证据/人物/事件指标，不能称法律正确率。

## H1—H4测量定义

| 假设 | 对照与固定条件 | 测量、方向及失败条件 |
|---|---|---|
| H1（主要）缺口驱动方法改善证据约束成功率 | M1−B3；同组、同初始观察、8次环境预算、相同通道及总生成预算 | 组配对成功率差及95%区间；区间跨0则不宣称改善。M0−B3作为策略工程贡献辅助分析；不能把M1整体增益全归策略 |
| H2 动作监督优于固定对话监督 | M1−D0；同基座、案件和有效监督token/计算预算 | 同主指标，报告真实训练成本；无正向差异或预算不匹配则不支持动作监督优势 |
| H3 反证/未决/可获取性状态降低无依据指控且保持覆盖 | 完整M1对移除此状态的消融；共享其余组件 | 无依据确定指控率降低；可解条件回答覆盖率下降不超过开发默认5个百分点。两个条件同时满足才支持，后续阈值修改只能在dev上版本化 |
| H4 先检索再针对性求助改善求助质量 | 先检索策略对直接泛化求助，固定相同用户可补充池和求助次数 | 每组必要且可回答且针对已观察缺口的问题比例、正确补充率、补充后支持性变化；另在等量补充信息匹配条件分析策略，不把增加通道的信息收益当规划收益 |

H3的“无依据指控率”为输出至少一项无观察支持的确定人物/罪名指控的案件组比例；同时报告逐主张支持精确率及可解覆盖。H4的必要性/可回答性由来源绑定标准评定，不能用Agent自己的评分替代。模拟用户与真人交互分别报告。

## 标注、划分、评分和统计

冻结既有训练身份，同案所有变体同集合，验证/测试不参与提示、标注示例或阈值选择。T01保守身份索引不替代T06跨来源同案审计。source-supported行为参与人与判决被告人分开记录。自动初审训练材料标为弱监督，独立评测gold需实际来源复核。

逐主张区分引用存在、原文对齐、语义支持；人物/角色、事件、罪名要件、多解释各有评分标准。未发生的人工复核不能填签署或通过。单人非法律专家限制必须披露，争议法律项暂缓或引入合格核对渠道。

按案件组配对bootstrap（开发默认10000次，seed=1729）估计差值95%区间；失败记录不丢弃。主要确认性比较为H1；H2—H4为支持性，若升级为确认性须在T42预设多重比较控制。样本量从dev方差和最小有意义差异规划；当前不承诺90案或70%就能证明优势。测试只在冻结活动中运行，观察结果后的实质修改需新实验版本并披露污染。

## 冻结与停止条件

协议、数据、环境、动作、模型、适配器、提示词、解码、评分器、代码、依赖及种子全部绑定摘要。缺文件或绑定不一致不得复用预测缓存。相同配置标识可重建，GPU随机性和数值差异仍需记录。

T01—T05完成后停止，本轮不自动开始T06。若五小时窗口剩余≤15%，立即停止新增工作，保存账本、日志和阻塞项，并同步main。额度未知时先报告未知并保留检查点，不猜剩余量。完整正式实验仍需后续授权和T42冻结。
