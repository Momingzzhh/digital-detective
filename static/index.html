如何开展案件研究

  1. 输入案件文字，或导入文字版 PDF、DOCX、TXT。
  2. 点击分析，助手将提取原文证据并检查矛盾。
  3. 根据助手问题补充线索；不存在或未知的信息请明确说明。
  4. 查看证据图谱及结论，点击引用回到证据原文。
  5. 导出 JSON 记录，供研究复核。

第一版只处理文字，不进行指纹图像、视频或 DNA 原始数据鉴定。输出是研究分析；证据不足时可以不作确定判断。

模型密钥：在项目 .env 中填写 DASHSCOPE_API_KEY，保存后无需重启。账号数据只保存在本机。
